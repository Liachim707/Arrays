# Arrays — собственная реализация ArrayList

## Описание проекта

Arrays — учебный Java-проект, в котором реализован собственный обобщённый список на основе обычного массива. Он демонстрирует, как устроена базовая структура данных, похожая на `java.util.ArrayList`, без использования готового ArrayList для хранения элементов.

## Что делает проект

Реализация `DefaultCustomArrayList<E>` поддерживает следующие операции:

- `add(element)` — добавляет элемент в конец списка;
- `get(index)` — возвращает элемент по индексу;
- `remove(element)` — удаляет первое найденное совпадение;
- `contains(element)` — проверяет, содержится ли элемент в списке;
- `size()` — возвращает количество элементов;
- `isEmpty()` — проверяет, пуст ли список;
- `clear()` — удаляет все элементы;
- `iterator()` — позволяет перебирать элементы, в том числе с помощью цикла `for-each`.

Внутри список хранит элементы в массиве `Object[]). Начальная вместимость — 10 элементов. Когда свободное место заканчивается, массив автоматически увеличивается вдвое. Реализация также поддерживает хранение и поиск значения `null).

Интерфейс `CustomArrayList<E>` описывает доступные операции, а класс `DefaultCustomArrayList<E>` реализует их.

## Структура проекта

- `src/CustomArrayList.java` — интерфейс списка;
- `src/DefaultCustomArrayList.java` — основная реализация;
- `src/CustomArrayListExample.java` — пример использования списка;
- `test/DefaultCustomArrayListTest.java` — автоматические тесты;
- `pom.xml` — конфигурация Maven и зависимость JUnit 5.

## Требования

- JDK 11 или новее;
- Apache Maven 3.6 или новее.

## Как запустить проект

### 1. Скачать проект

Клонируйте репозиторий:

```bash
git clone https://github.com/Liachim707/Arrays.git
cd Arrays
```

### 2. Запустить пример

Откройте проект в IntelliJ IDEA, найдите файл `src/CustomArrayListExample.java` и запустите метод `main()` с помощью зелёного значка запуска рядом с ним.

Пример создаёт список строк, добавляет элементы, проверяет наличие элемента, получает и удаляет элемент, перебирает список и очищает его.

### 3. Запустить автоматические тесты

В корневой папке проекта выполните:

```bash
mvn test
```

Maven скачает необходимые зависимости, скомпилирует проект и запустит тесты JUnit 5.
