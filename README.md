# Arrays — собственная реализация ArrayList

## Описание проекта

Arrays — учебный Java-проект, в котором реализован собственный обобщённый список на основе обычного массива. Проект показывает, как устроена базовая структура данных, похожая по назначению на `java.util.ArrayList`, без использования готового ArrayList для хранения элементов.

## Что делает проект

Реализация `DefaultCustomArrayList<E>` поддерживает следующие операции:

- `add(element)` — добавляет элемент в конец списка;
- `get(index)` — возвращает элемент по индексу;
- `remove(element)` — удаляет первое найденное вхождение элемента;
- `contains(element)` — проверяет, содержится ли элемент в списке;
- `size()` — возвращает количество элементов;
- `isEmpty()` — проверяет, пуст ли список;
- `clear()` — удаляет все элементы;
- `iterator()` — позволяет перебирать элементы, в том числе с помощью цикла `for-each`.

Внутри используется массив `Object[]`. Начальная вместимость — 10 элементов. Когда свободное место заканчивается, массив автоматически увеличивается в два раза. Реализация поддерживает хранение и поиск значения `null`.

Интерфейс `CustomArrayList<E>` описывает доступные операции, а класс `DefaultCustomArrayList<E>` реализует их.

## Как запустить проект

### 1. Скачать проект

Клонируйте репозиторий и перейдите в его папку:

```bash
git clone https://github.com/Liachim707/Arrays.git
cd Arrays
```

### 2. Запустить пример

Откройте проект в IntelliJ IDEA, выберите JDK 11 или новее, найдите файл `src/CustomArrayListExample.java` и запустите его метод `main()` с помощью зелёного значка запуска рядом с методом.

Пример создаёт список строк, добавляет элементы, проверяет наличие элемента, получает и удаляет элемент, перебирает список и очищает его. Результат будет показан в окне Run.

### 3. Запустить автоматические тесты

В корневой папке проекта (там, где находится `pom.xml`) выполните:

```bash
mvn test
```

Maven загрузит необходимые зависимости JUnit 5, скомпилирует исходный код и запустит автоматические тесты.
